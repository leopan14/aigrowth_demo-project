V2.0 定位 客户输入增长目标,12 个自主 Agent 协作完成「诊断 → 定位 → 用户定义 → 验证 → 创意 → 触达 → 销售 → 复盘」全链路闭环,直接交付可归因的增长结果。人在边界,不在流程中。
①
目标驱动
客户输入的是增长目标,不是配置项;系统内部自主拆解、规划、执行
②
人在边界
人不在流程中,而在边界条件中(红线、预算上限、品牌底线);触发红线熔断、其余 Agent 自决策
③
自验证闭环
AI 输出不可直接执行,必须经 Persona 池预验证或影子流量验证;每个生成式 Agent 内置 Critic 子模块
L6
治理层
Governance Layer
⟂ 横切监督所有上层
V1.0 的 8 层横向治理在 V2.0 中被重新组织为 Policy-as-Code。L6 是 AI 原生与传统 RPA 工作流的最大分水岭——RPA 靠人审批,AI 原生靠 Policy + Observability + Kill Switch 三件套实现"自由地跑、严格地控"。
L6 监督的对象:
L1 客户输入合规 L2 Planner DAG 预审 L3 每个 Agent 决策 L4 World Model 写入 L5 数据资产采集 / 回流
